## Steps

1. If Chrome is not already running, open Chrome (e.g., Spotlight: Cmd+Space → type "Chrome" → Enter). If Chrome is running, switch to it.
2. If a Google Maps tab is already open and showing search results for the target (e.g., "Wentworth, New South Wales, Australia"), activate that tab. Otherwise, go to https://maps.google.com in Chrome (click the address bar then type or paste the URL and press Enter).
3. Focus the Maps search box (click it or press Tab until focused), type the exact place query (for example: `Wentworth, New South Wales, Australia`) and press Enter.
4. From the search results, open the place page: click the place result or the place name in the left info panel so the full place card opens (confirm the left panel title reads the place name).
5. Adjust the map zoom and pan until the place label (e.g., "Wentworth") and the nearby geographic features you need (e.g., the Murray and Darling Rivers) are clearly visible:
   - Use the + / − zoom buttons at bottom-right of the map or scroll the mouse/trackpad while the cursor is over the map.
   - Click-and-drag the map to reposition, or use two-finger drag on a trackpad.
6. Copy the canonical Maps place URL to the clipboard:
   - Press Cmd+L to focus the address bar, then press Cmd+C to copy the URL.
   - (Optional) Paste into a text editor (Cmd+V into TextEdit) to confirm the correct URL was copied.
7. Capture a screenshot showing the map area with the place label and nearby features:
   - To capture the whole browser window: press Cmd+Shift+4, then press Space, then click the Chrome window.
   - To capture a custom region: press Cmd+Shift+4, then drag to select the map region and release.
   - Save the screenshot or confirm it was captured.
8. Report completion and, if needed, paste the copied URL where requested.

## Tips

- If multiple places with the same name appear, prefer the result whose info card indicates the correct state/country and description (e.g., "Town in New South Wales").
- Use the place card on the left as confirmation that the place page is open; it often contains the place name, photos, and the pin details.
- Zoom controls are at the bottom-right; keyboard shortcuts (Cmd+Plus / Cmd+Minus) affect browser zoom, not map zoom—use the map's controls or scroll wheel for map zoom.
- If Maps is slow to load, wait for the left info panel to show the place name before copying the URL.
- For reproducible captures, prefer the address-bar copy (Cmd+L → Cmd+C) over copying the map pin share link in the UI unless a short "share" link is specifically needed.
