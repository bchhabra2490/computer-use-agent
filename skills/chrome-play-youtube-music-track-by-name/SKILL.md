description: >-
  Finds and starts playback of a named song on YouTube Music in Google Chrome on macOS. Prefers an existing YouTube Music tab when available, otherwise opens music.youtube.com, searches for the track (optionally with artist), starts playback, and performs quick audio checks if no sound is heard.
---

## Steps

1. Bring Google Chrome to the front (Spotlight Cmd+Space → type Chrome → Enter).
2. Look for an existing tab whose URL matches music.youtube.com or contains "YouTube Music". If found, switch to that tab.
3. If no suitable YouTube Music tab exists: open a new tab (Cmd+T), type `music.youtube.com` and press Enter. Wait for the page to finish loading.
4. Focus the YouTube Music search box (click the search icon or press `/` if available), type the song name and optionally the artist (e.g. `Lag Ja Gale Lata Mangeshkar`), then press Enter.
5. In the search results, locate the Tracks section (or the first matching track). Click the track's title or the track's play button to start playback.
6. Verify playback started by checking that the player shows a Pause icon and a progress bar/time counter is moving.
7. If you cannot hear audio, perform quick checks:
   - Right-click the Chrome tab and select "Unmute site" if it is muted.
   - In the YouTube Music mini-player, click the speaker icon (if present) to ensure the player is not muted and adjust its slider.
   - Open the macOS sound menu (speaker icon in the menu bar) and confirm the correct output device is selected and system volume is up.
   - If using AirPlay/Cast, click the player’s device/CAST button and select the desired output device.
8. Once audible, stop. Do not wait for the song to finish; leave playback running or pause it as requested.

## Tips

- If the search returns many covers, add the artist name or the word "official" to the query to find the original recording.
- If Chrome blocks autoplay, click the player area directly to trigger playback.
- To avoid disturbing other displays or windows, prefer an existing YouTube Music tab rather than opening a new window.
- If you need a local music app instead of YouTube Music, replace steps 2–5 with opening the Music app (Spotlight) and searching within it for the song.
