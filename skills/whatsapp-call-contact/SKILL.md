  Starts a WhatsApp Desktop voice or video call with a named contact on macOS; useful when the user wants a reproducible sequence to find a contact and initiate a call.
---

## Steps

1. Open WhatsApp Desktop:
   - Press ⌘+Space, type "WhatsApp", and press Enter; or run open -a WhatsApp.
   - Wait until the WhatsApp window is frontmost.

2. Focus the left-column contact search (Chats search):
   - Click the Search box at the top of the left column (under "Chats").
   - If the message input area is accidentally focused, click inside the message input, press ⌘A then Backspace to clear it before continuing.

3. Type the contact name exactly as you know it (e.g., Bhaskar) and press Enter or click the matching contact in the search results to open the chat.

4. Start the call:
   - For a voice call: click the phone/handset icon in the chat header (top‑right of the chat window).
   - For a video call: click the camera icon in the chat header (top‑right).

5. Confirm call started visually (call UI appears) and use the on-screen controls to mute/unmute, enable/disable camera, or end the call when finished.

## Tips

- If no match appears, try alternate spellings or fewer characters (e.g., last name only) and check the contacts list manually by scrolling.
- When multiple matching results appear, verify the right contact by profile picture or last message preview before calling.
- If WhatsApp does not have microphone/camera permissions, macOS will prompt; grant them in System Settings → Privacy & Security → Microphone/Camera.
- If WhatsApp is minimized or on another Space, use ⌘+Tab to bring it forward instead of launching again.
- To avoid accidentally sending typed text while searching, always ensure the left-column search box is focused (not the message input) before typing the contact name.
