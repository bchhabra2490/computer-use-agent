name: google-maps-open-place
description: >-
  Opens Google Maps in Chrome (or uses an existing Maps tab), searches for a
  specified place, opens the place page, and adjusts zoom so the place label
  and nearby features are visible. Use when asked to show a town/place on a map.
---

## Steps

If Maps already shows the requested place (recipe or a previous step opened it), skip to zoom or mark_done. Do not reopen Chrome or type a new search.

1. If Chrome is not already running, open Chrome (e.g., Spotlight: Cmd+Space → type "Chrome" → Enter). If Chrome is running, switch to it.
2. If a Google Maps tab is already open and showing search results for the target (e.g., "Wentworth, New South Wales, Australia"), activate that tab. Otherwise, go to https://maps.google.com in Chrome (click the address bar then type or paste the URL and press Enter). Prefer opening `https://www.google.com/maps/search/?api=1&query=` plus the place name when that is faster than typing in the Maps search box.
3. Focus the Maps search box (click it or press Tab until focused), type the exact place query (for example: `Wentworth, New South Wales, Australia`) and press Enter — unless the place is already loaded from the search URL.
4. From the search results, open the place page: click the place result or the place name in the left info panel so the full place card opens (confirm the left panel title reads the place name).
5. Adjust the map zoom and pan until the place label (e.g., "Wentworth") and the nearby geographic features you need (e.g., the Murray and Darling Rivers) are clearly visible:
   - Use the + / − zoom buttons at bottom-right of the map or scroll the mouse/trackpad while the cursor is over the map.
   - Click-and-drag the map to reposition, or use two-finger drag on a trackpad.
6. Stop when the place is on screen and readable. Do not copy the Maps URL. Do not take a screenshot unless the user asked for one.

## Tips

- If multiple places with the same name appear, prefer the result whose info card indicates the correct state/country and description (e.g., "Town in New South Wales").
- Use the place card on the left as confirmation that the place page is open; it often contains the place name, photos, and the pin details.
- Zoom controls are at the bottom-right; keyboard shortcuts (Cmd+Plus / Cmd+Minus) affect browser zoom, not map zoom—use the map's controls or scroll wheel for map zoom.
- If Maps is slow to load, wait for the left info panel to show the place name before zooming.
