## Steps

1. Open Google Chrome on the Mac (Spotlight: Cmd+Space → type "Google Chrome" → Enter).
2. In Chrome, open a new tab (Cmd+T).
3. In the address bar, navigate to the ChessInsights site: either paste the known URL if available or search for "ChessInsights" and follow the top result to the app. Press Enter and wait for the page to finish loading.
4. If the site shows a landing page, click the button or link to start a new game (labels may be "Play", "New Game", "Start", or similar).
5. Open the game mode / settings or look for a visible mode toggle. Enable Blindfold mode (it may be labeled "Blindfold", "Blindfold Mode", an eye/visibility icon, or a "Hide board" option). If you can't find a single toggle, open Settings/Options → Board Visibility and select the option to hide the board or enable blindfold play.
6. Choose the desired opponent (Computer / Human) and time control if prompted, then start the game.
7. Verify blindfold mode is active: the visual chessboard should be hidden or obscured and only moves/notation or a minimal UI should be visible. Also verify any on-screen indicator that confirms "Blindfold" is enabled.
8. Bring the ChessInsights tab/window to the front and keep it focused. Confirm visually in Chrome that the new blindfold game is active and the UI is awaiting the first move.
9. Report back (or display) a short ready message such as: "Blindfold game started on ChessInsights — waiting for your first move." Leave the game tab frontmost until the user provides the move.

## Tips

- If ChessInsights prompts for sign-in, choose the guest or "play without account" option if available to avoid blocking the flow; otherwise sign in and then start a new blindfold game.
- If you cannot find a labeled "Blindfold" control, look for Settings → Board Visibility, Accessibility, or Display options to hide the board.
- If the page doesn't load or the UI is unresponsive, reload the tab (Cmd+R) and try steps 4–6 again.
- Do not attempt to 'wait' for long media or use system speech; simply leave the ChessInsights window frontmost and indicate readiness to the user.
