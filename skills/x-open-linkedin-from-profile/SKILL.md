name: x-open-linkedin-from-profile
description: >-
  Find a person's LinkedIn profile starting from an X (Twitter) chat/profile in the frontmost Google Chrome window and open that LinkedIn profile in a new browser tab. Use when you need to jump from an X conversation/profile to the person's LinkedIn.
---

## Steps

1. Confirm Google Chrome is the frontmost app and the active tab shows the X chat or the person's X profile.
2. Open the person's X profile:
   - If you're in a DM, click the sender's display name, handle, or avatar at the top of the chat to open their X profile page.
   - If a profile preview is visible next to a message, click it to open the full profile.
3. Look for an explicit LinkedIn link on the X profile:
   - Check the bio and the links row for a linkedin.com URL or LinkedIn icon.
   - If you see a LinkedIn link or icon, Cmd+Click it (⌘-click) or right-click → "Open link in new tab" to open the profile in a new Chrome tab.
4. If no LinkedIn is visible but a personal website/portfolio link is present:
   - Cmd+Click the website link to open it in a new tab.
   - In the site tab, scan for a LinkedIn icon/link (usually in the page header, footer, or "Contact/About"). Cmd+Click or right-click → "Open link in new tab" on the LinkedIn link.
5. If clicking the link only hovers a URL (status bar) or a redirect shortener is used:
   - Right-click the link → "Copy link address".
   - Open a new Chrome tab (⌘+T), paste the URL into the address bar, and press Return to open it.
6. Verify the opened tab is a LinkedIn profile by checking the URL begins with "https://www.linkedin.com/in/" or contains "linkedin.com" and that the page shows a person’s profile.
7. If no LinkedIn link is found on profile or site, perform a targeted search in the omnibox: site:linkedin.com "Full Name" plus any differentiator (company/handle) and open the best match in a new tab.

## Tips

- Prefer Cmd+Click to open links in a background tab without losing your current X tab.
- Use right-click → "Open link in new tab" when Cmd+Click is blocked by the site.
- Confirm domain contains linkedin.com before opening to avoid phishing redirects; if the site uses a redirector, copy the final URL before visiting.
- If multiple LinkedIn profiles appear in search results, prefer the result that matches the X profile's name, current company, or location.
- If the X profile already lists a canonical LinkedIn URL, open that directly rather than searching.
