## Steps
1. Open the EasyEDA from either Mac Dock or Launcher. Do not use browser website of easyeda.
2. Create a new project.
3. Enter the requested descriptive project name in the name field. Replace any existing name only if the user asked to rename the project.
4. Click **Save** or **Confirm**.
5. If EasyEDA Pro shows an additional location, project, overwrite, or confirmation dialog, review it and select the option that completes the save without altering the schematic.
6. Wait for the dialogs to close and verify that the new name appears in the project or document title area, or that EasyEDA Pro otherwise indicates the save succeeded.

## Tips
- Prefer menu labels over fixed coordinates because EasyEDA Pro layouts and window sizes vary.
- Do not redraw, move, delete, or modify circuit elements while saving.
- If an overwrite warning appears unexpectedly, verify the destination and filename before confirming.
- Preserve the user’s spelling, capitalization, underscores, and other filename formatting exactly.
