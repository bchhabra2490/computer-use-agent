---
name: check-mac-storage
description: >-
  Finds the Mac’s available storage and total capacity using the System Settings interface when the user asks about disk space or storage usage.
---

## Steps
1. Open **System Settings** using Spotlight (`Cmd+Space`, type `System Settings`, then press `Return`).
2. Select **General** in the sidebar.
3. Click **Storage**. If it is difficult to locate, use the System Settings search field to search for `Storage`, then select the Storage result.
4. Wait for macOS to calculate and display storage usage.
5. Read the available amount and total capacity from the storage summary near the top of the page. Record the used amount too if it is readily shown.
6. Report the figures without clicking recommendations, deleting files, or changing settings.

## Tips
- The summary may be phrased as “X GB available of Y GB” or may separately show used and available space.
- Storage categories can take several seconds to finish calculating.
- Use the values exactly as displayed; do not infer capacity unless necessary.
- Do not open optimization recommendations or modify storage settings.
