---
name: chrome-move-tab-to-display-and-fullscreen
description: >-
  Moves an existing or newly-opened Chrome tab that contains a specified image/diagram or webpage to a named external display and makes the Chrome window fullscreen so the diagram fills that monitor. Use when you need a specific image or page visible and maximized on a particular attached display.
---

## Steps

1. Bring Google Chrome forward:
   - Click any Chrome window or press ⌘+Tab until Chrome is the frontmost app.

2. Look for an existing tab that already shows the requested diagram or keywords:
   - Press ⌥⌘+A or open Chrome's tab strip and scan tab titles for the keyword (e.g., "TP4056", "pin", "pinout", "datasheet").
   - If you find a matching tab, click it to make that tab active and skip to step 5.

3. If no existing tab matches, perform a targeted search in Chrome:
   - Click the address bar (⌘+L), type the query (for example: TP4056 pin diagram), and press Return.
   - Optionally switch to the Images results by clicking "Images" beneath the search box to find a full-quality diagram quickly.

4. Open a clear diagram or datasheet from the search results:
   - In the Images tab, click a thumbnail that looks like a pinout or datasheet preview to open its preview.
   - From the preview: click the image itself or choose "Open image" / "Visit" (or right-click → "Open image in new tab") to load the full-resolution image or the datasource page in a tab.

5. Make the Chrome window containing the diagram the active window:
   - If the diagram is in a background Chrome window, click anywhere inside that window so it becomes frontmost on whatever display it is currently on.

6. Move the Chrome window to the named external display (e.g., "L27i-40"):
   - Click and drag the window by its title bar and move it across to the target monitor until the window appears on that display.
   - If you prefer keyboard/mission-control: enter Mission Control (F3 or swipe up) and drag the window's thumbnail to the desktop area for the target display, then exit Mission Control.

7. Enter fullscreen so the diagram fills the monitor:
   - With the Chrome window active on the target display, press Control+Command+F to toggle fullscreen for that window.

8. Ensure the diagram is the full-resolution view and fills the screen:
   - If the page shows only a small preview, click the previewed image or its tab to open the full image/tab.
   - Reset zoom with ⌘0, then use ⌘+ repeatedly until the pinout/diagram visually fills the display.

9. Verify completion:
   - Confirm the diagram is clearly readable and occupies the L27i-40 display in fullscreen.

## Tips

- If you are not sure of the monitor name, open System Settings → Displays to confirm the external monitor's name/position before dragging.
- If Chrome has multiple windows and you opened a new tab in the wrong window, right-click the tab → "Move tab to another window" and then drag that window to the target display.
- Use right-click → "Open image in new tab" or the search result's "Visit" link to get the original full-resolution diagram rather than a compressed preview.
- If fullscreen keyboard shortcut (Control+Command+F) behaves differently for your Chrome installation, click the green traffic-light button while holding Option to toggle maximize vs fullscreen.
- If the diagram is still too small after zooming, try opening the image URL directly in a tab (right-click → "Copy image address", open new tab, paste, and Enter) to remove surrounding UI and then fullscreen.
