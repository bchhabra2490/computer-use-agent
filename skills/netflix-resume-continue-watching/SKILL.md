## Steps

1. Open the default web browser (or Google Chrome) on macOS.
2. Focus the address bar (Cmd+L) and navigate to https://www.netflix.com. If Netflix is already open in a tab, bring that tab to the front.
3. If a Sign In button is visible, click it and sign in with the active Netflix account. Use saved credentials / macOS Keychain if available; pause for any required 2‑factor auth or manual OTP entry.
4. If the profile picker appears, click the correct user profile to open the Netflix homepage.
5. On the homepage, locate the "Continue Watching" row. If the page needs scrolling, scroll horizontally/vertically until that row is visible.
6. In the "Continue Watching" row, choose the first item or the first item that visibly shows progress (a progress bar/indicator). Click its thumbnail or title to open the show/episode page or the player overlay.
7. If a play overlay appears, click the Play button to start playback. If Netflix opens the episode directly, reveal player controls by clicking near the center of the video area.
8. If a device/cast chooser appears (offering other devices), choose the entry that corresponds to the local computer (labels like "This computer", the machine name, or "Play on this device").
9. Wait briefly to confirm video playback has started: look for the Pause button in the player controls or visible motion/elapsed time. Optionally press the spacebar or 'k' to toggle play/pause to confirm.
10. Pause the video after confirming playback has started.
11. Report back that playback was started and paused, including the show title/episode if visible.

## Tips

- Use Google Chrome for most consistent behavior on macOS; open it via Spotlight (Cmd+Space → type "Google Chrome" → Enter) if needed.
- If Netflix prompts for 2FA or email link sign-in, wait for manual user input; note this step will block automation until complete.
- If the "Continue Watching" row is absent, check "Continue Watching for [profile]" by scrolling farther down the homepage, or open the profile's Activity/Viewing Activity page to identify the most recent item.
- If the player is cast to another device unexpectedly, clicking the cast/device icon in the player controls will re-open the chooser; select the local device entry.
- Keyboard shortcuts: space or K toggles play/pause; F toggles fullscreen; M toggles mute — useful to verify playback without clicking UI elements.
- If the video doesn't start within a few seconds, reload the tab (Cmd+R) and retry steps 6–9; capture a screenshot of any error message for troubleshooting.
